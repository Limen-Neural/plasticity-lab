# Delayed-reward association experiment record

This record preserves the declarations and results from the 2026-10-02
[LIM-1298](https://linear.app/rpd-34/issue/LIM-1298) experiment. It was separated
from local planning notes without changing the protocol or results. The runnable
task is `tests/association.rs`: synthetic, generated by this file, no external data.

## Declared before development

- Classes: A activates channels 0–1; B activates 2–3. Equal-share weights,
  no class-specific initialization. Aligned labels A → 1, B → 0; shuffled
  labels swap within each balanced pair. Keep the modulation-disabled control.
- K = 8 intervening silent ticks; tau_eligibility = 100.
- Development seeds **1, 2, 3**; final seeds **11, 29, 47, 71, 101**.
- Disjoint caller-owned trial IDs: train **0–3**, development **100–107**,
  final **200–207**; separate split-specific stimulus/order RNGs.
- Metric: **class-conditional spike-rate discrimination**, D = frozen spikes
  per neuron per tick for A minus the rate for B. No fitted decoder; neither
  training reward averages nor weight contrast establishes held-out success.
- Fixed criterion: **D_aligned ≥ 0.05 and D_aligned − D_shuffled ≥ 0.05 for
  every final seed and for the arithmetic mean**. Never drop an unfavorable seed.
- Tune only on development data. A failed final comparison must be reported;
  any revised protocol requires disclosure and a fresh final split, not a
  weakened margin or silent reuse of final results for tuning.

## Development and protocol lock, before final scoring

The first implemented protocol passed without parameter tuning:

| --- | ---: | ---: | ---: |
| 1 | 0.166667 | -0.166667 | 0.000000 |
| 2 | 0.291667 | -0.291667 | 0.000000 |
| 3 | 0.166667 | -0.166667 | 0.000000 |

The exact parameters were then locked before evaluating any final seed:

- Two LIF neurons, no Izhikevich neurons, four channels; weights 0.5, initial
  threshold 0.12, other neuron defaults unchanged.
- Four training trials: four pairing ticks, eight silent ticks, one silent
  payout tick each (52 ticks total). Last stimulus is tick 4, payout tick 13.
  Reset episodes before each trial, not during the delay; preserve learned
  weights/thresholds while clearing runtime, traces, and dopamine.
- Training pair amplitude: 0.8 × Uniform[0.9, 1.1). Readout pair amplitude:
  0.15 × Uniform[0.9, 1.1) to avoid saturation. Eight readout trials, six ticks
  each (48 ticks total); matched amplitude within each A/B pair.
- Upstream RmStdpConfig: tau_eligibility 100, reward_lr 8, bounds [0, 2].
  RewardMapping dopamine_gain 1; other mapping defaults unchanged.
- SmallRng stimulus/order seed: `seed ^ ((split_start + 1) << 32)`;
  training-engine seed: `seed`; evaluation-engine seed: `seed ^ 0xE7A1_0000`.
  Clone identical condition streams; never reseed per tick.
- Independent checkpoint-derived evaluation state for each trial. Reset runtime
  and restore checkpoint traces/persistent modulators, preserving all plasticity
  bits before and after `run_eval_with_rng` with default evaluation modulators.
  Discard evaluation state; original training checkpoints and RNGs stay untouched.
- No optional same-step ablation; modulation-disabled remains the third control.

Protocol, score-arithmetic, delayed-credit, and replay checks passed. A temporary
mutation replacing frozen evaluation with ordinary training failed the plasticity
bit assertion even with zero dopamine. That mutation was removed before final
evaluation. No final seed had been evaluated when these parameters were locked.

## First final evaluation: passed without protocol revision

```bash
cargo test --locked --test association association_delayed_reward_beats_paired_shuffled_on_frozen_holdout -- --exact --nocapture
```

| Final seed | Aligned D | Shuffled D | Disabled D | Paired advantage |
| --- | ---: | ---: | ---: | ---: |
| 11 | 0.166667 | -0.166667 | 0.000000 | 0.333333 |
| 29 | 0.333333 | -0.333333 | 0.000000 | 0.666667 |
| 47 | 0.250000 | -0.333333 | 0.000000 | 0.583333 |
| 71 | 0.333333 | -0.333333 | 0.000000 | 0.666667 |
| 101 | 0.166667 | -0.208333 | 0.000000 | 0.375000 |
| **Mean** | **0.250000** | **-0.275000** | **0.000000** | **0.525000** |

All five seeds and the mean exceeded both fixed margins. No seed was omitted;
no parameter or margin changed after final scoring. Subsequent unchanged
default/all-feature suite runs reproduced success.

Environment: Linux x86_64, Rust 1.98.1, registry neuromod 0.7.0, rand 0.10.3,
unchanged Cargo.lock. SmallRng results are version/target dependent. This is
evidence for this synthetic assay, not general task accuracy or superiority
to same-step reward. See the [README protocol](../../README.md#delayed-reward-association-benchmark-unreleased-v03).
